# KamiTomo foods and drinks: art list

The food and drink menu for the spirit (kami) version of the game. Agreed with Xavi on 2026-10-26.
This is the list to draw from.

## The idea

- The spirits get **offerings**: mostly East Asian offering and festival foods, plus a few
  **world foods** (burger, donut, pancakes…) as the odd offering. Feeding a spirit something
  strange is part of the fun.
- The menu should work in **any home**, not only the hokora (later homes may be very different,
  for example a futuristic little house with a neon sign), and in **any Asian market**.
- The structure stays the same: 5 families (Green, Sweet, Greasy, Spicy, Sour) x 3 sizes
  (Baby, Kid, Adult) x 3 foods = 45 foods, plus 15 drinks (5 types x 3 levels). Each new food
  takes the slot of the one it replaces, so the evolutions don't change.

## Art rules

- **Size and format:** 32 x 32 px PNG icons, like every food and drink icon now.
- **Where they go:** `textures/food/` and `textures/drinks/`. The NEW SHRINE look reads its own
  version from `textures/food/new_shrine/` and `textures/drinks/new_shrine/` under the same file
  name, so draw new icons for both folders, as with the current set.
- **File names:** lowercase, no spaces (the suggested name for each new icon is in the tables).
- **Draw a dish's shared form.** Dumplings, rice balls, skewers, rice cakes, noodles and pickles
  exist across Japan, China and Korea. Draw the form all of them would recognise (a plain pleated
  dumpling, a round rice ball), not a version that belongs to one country. Each language gives the
  dish its local name (see Naming).
- **Avoid:** the rising-sun motif (sun rays behind food, flag-like stripes), real deities' names
  or faces, and anything that makes fun of the offering rite itself.

## Naming across countries

- **Shared dishes get neutral English names**, and each translation uses the local word:
  Dumplings (Gyoza / Jiaozi / Mandu), Rice Ball (Onigiri / Fantuan / Jumeokbap), Skewers
  (Yakitori / Chuan'r / Kkochi), Rice Cake (Mochi / Niangao / Tteok), Barley Tea (Mugicha /
  Damai Cha / Boricha), Pickles (Tsukemono / Paocai / Jangajji).
- **Dishes with a strong national identity keep their own name everywhere:** Kimchi, Kappa Maki,
  Inari Sushi, Okonomiyaki, Yakisoba, Ikayaki, Mooncake, Ramune, Bubble Tea. Never translate
  Kimchi as "Paocai" (a real dispute between Korea and China).
