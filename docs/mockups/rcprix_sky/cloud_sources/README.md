# Sky drifting clouds · ImageGen sources

Six high-resolution transparent source paintings for the RC Prix Sky drifting clouds. The game conversion supplies final pixel size, transparency and movement. The paintings are solid so the game can control opacity.

| Source | Intended game size |
| --- | --- |
| `cloud_large_a_source.png` | About 160 × 100 px |
| `cloud_large_b_source.png` | About 160 × 100 px |
| `cloud_medium_a_source.png` | About 100 × 60 px |
| `cloud_medium_b_source.png` | About 100 × 60 px |
| `cloud_small_a_source.png` | About 50 × 30 px |
| `cloud_small_b_source.png` | About 50 × 30 px |

Made individually with the built-in ImageGen tool. The accepted stand-cloud source supplied the white, blue and lavender palette and clustered shading. Prompts requested a directly overhead view, one continuous rounded cloud per image, top-left light, no glow and a transparent background. These are source paintings, not game-grid sprites.
