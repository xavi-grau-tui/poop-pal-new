# RC Prix Sky · start platform concepts

Three transparent high-resolution ImageGen concept paintings for a possible replacement of the current steel drone pad. These are **choice concepts**, not finished game-grid sprites. The selected design can be developed as a full piece after review. Each is intended for a roughly **104 × 94 game px** platform, seen from the game's elevated overhead view with light from the upper left.

| File | Concept |
| --- | --- |
| `platform_A_grassy_islet.png` | Floating grassy islet, dirt runway, checkered line, windsock, small wooden hangar and earthy underside |
| `platform_B_balloon_deck.png` | Wooden deck suspended from colourful balloon clusters, open runway and checkered line |
| `platform_C_cloud_runway.png` | Solid cumulus platform with striped carpet runway, bunting, lights and checkered line |

Made with the built-in ImageGen tool, one prompt per concept. The common prompt specified the toy-plane starting-platform footprint, open central runway, top-left light, clustered pixel-art finish, transparent background and no plane or interface. Each concept prompt supplied its own structure and decorations. Lagoon island, Sky stand-cloud, current pad guide and wood artwork were style or layout references as applicable.
