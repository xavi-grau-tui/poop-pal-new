# Sky hot-air balloons · ImageGen sources

Four high-resolution transparent source paintings for the obstacles in RC Prix Sky levels 25–27. Convert each to about **26 × 34 game px**. Preserve the central cap, broad envelope panels, short ropes and small attached basket so the silhouette remains readable on the phone.

| Source | Stripe colours |
| --- | --- |
| `balloon_red_yellow_source.png` | Red / yellow |
| `balloon_blue_white_source.png` | Blue / white |
| `balloon_purple_green_source.png` | Purple / green |
| `balloon_pink_white_source.png` | Pink / white |

Made with the built-in ImageGen tool. The red/yellow painting established the shape; the other three were ImageGen edits preserving its layout and changing only the colours. Prompts specified a straight-down view, top-left light, rich clean pixel-art shading, transparent background and no glow. These are source paintings, not game-grid sprites.
