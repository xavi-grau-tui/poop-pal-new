# Neon Cyber Shrine — Step A concept

This folder contains **one front-view concept** for home 1. The artwork and separate coloured guide were made with the built-in ImageGen tool. No home layers were generated.

| File | Purpose |
| --- | --- |
| `concept_imagegen_source.png` | Original transparent ImageGen painting (1254 × 1254) |
| `concept_110.png` | 110 × 110 art-pixel review image |
| `concept_8x.png` | Exact 8× nearest-neighbour enlargement of `concept_110.png` (880 × 880) |
| `fixed_points_guide_imagegen.png` | Separate, illustrative marker layer at source size |

The 110-pixel review image was downsampled with **nearest neighbour**, and its alpha was made binary (fully transparent or fully opaque). No smoothing was used in the 8× preview. This technical export did not draw or repaint the design.

## Fixed-point review

The guide layer marks: red = spirit window, blue = hanging beam, orange = lantern hooks, gold = far-left bell hook, green = shelf spots, yellow = offering table. ImageGen markers are **visual annotations, not pixel-exact anchor data**. Use the existing [`guide_hanging.png`](../../hokora_decor/guide_hanging.png), [`guide_shelf.png`](../../hokora_decor/guide_shelf.png), and forest `textures/pet/shrine_new/front.png` as the authoritative positions when testing the concept. The final layer-cutting step should begin only after those points are checked in-game.

## Recolourable materials

1. Blue-grey metal roof, supports and platform.
2. Teal and magenta LED strips.
3. Cable jackets around the side supports.

The CRT screen, two lantern hooks, left bell hook, hanging beam, low offering table and two side shelf ledges are visible in the concept. The central opening remains clear for the spirit.

## ImageGen prompt

The concept was generated by editing the forest hokora into a dark metal shrine with teal and magenta eave LEDs, cables, a small CRT in the rear of the opening, the same roof shape and an open spirit window. The final targeted edit prompt was: “Keep the provided Neon Cyber Shrine exactly as drawn: same roof, eaves, central window, cable paths, lanterns, bell, side ledges, offering table, silhouette, proportions, colours and big hard pixel blocks. Change only the small object on the back wall near the top of the opening from a round mirror to a small square vintage CRT monitor with a blank teal screen and one blocky control knob. Preserve transparent background; no text, glow, antialiasing or scenery.”
