# ImageGen prompt set for the v5 homes

Built-in ImageGen was used for every new visible design. Each front used four
image references: its earlier home concept, the approved 220-grid Tree Hollow,
`textures/pet/shrine_new/front.png`, and its matching `v5_notes_*.png` card.
Each table used its new front plus the approved Tree Hollow table. The Fire
room used the Fire front plus Tree Hollow room; the Capsule and Arcade glass
used their new fronts. The source PNGs are saved in each home folder.

The common front prompt was: “Create one finished, empty front for this home.
Preserve the concept's distinctive silhouette. Match Tree Hollow and the
forest hokora on a 220-art-pixel grid: continuous 2-pixel dark plum outer
outline, inner shapes outlined at 1–2 pixels, 3–4 clean flat tones per
material and top-left highlights. The central spirit opening is real
transparency following its own edge. Keep clear shelf ledges and a clear
central table position on floor row 162; include beam and attachment points.
Transparent background. No spirit, table, lanterns, bell, shelf objects, sky,
gradient, blur, noise or painted glow.”

Home-specific additions:

- **Neon Cyber:** graphite metal, teal and magenta LED trim, cables, CRT-like
  frame; metal plinth table with LED edge.
- **Moon:** pale cratered stone pavilion on a floating rock, crescent, lilac
  trim; stone pedestal table with crescent.
- **Golden Temple:** taller multi-tier gold-leaf and black-lacquer pagoda;
  black lacquer sanbo table with gold corners.
- **Ruined Night:** tall asymmetric collapsed roof, roots, mushrooms, old
  blue-grey timber; cracked sanbo propped on stone.
- **Food Stall:** wooden yatai cart with full wheels, fabric awning and counter;
  lacquered serving board on a solid wooden block.
- **Capsule Apartment:** tall rounded white pod with two genuine side window
  holes; white plastic side table and separate translucent blue side glass.
- **Arcade Cabinet:** tall red upright cabinet, empty CRT opening, left
  joystick and right buttons; separate coin-box table and CRT glass.
- **Bathhouse:** taller tiled sento corner, Fuji tile panels, short noren;
  wooden stool and bucket table.
- **Fire Shrine:** volcanic basalt, flat ember fissures, iron roof with raised
  ends, forge chimney and chili strings; separate calm basalt room and anvil.

The technical exporter performs canvas alignment, nearest-pixel placement,
front/inside separation, alpha clipping for the glass, and review previews.
No design is drawn by the exporter.
