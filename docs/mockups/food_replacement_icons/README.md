# Food and drink icon handoff

Thirteen 32×32 transparent PNG sprites are ready under both the existing and New Shrine texture folders. Each is the same image in both locations so the game can use one design across both looks.

## Replacement mapping

| New sprite | Replaces |
| --- | --- |
| `cucumber.png` | Avocado |
| `riceball.png` | Salad Bowl |
| `konpeito.png` | Cookie |
| `ricecake.png` | Macaron |
| `mooncake.png` | Choco Cake |
| `aburaage.png` | Onion Rings |
| `yakisoba.png` | Spaghetti |
| `okonomiyaki.png` | Pizza Slice |
| `inarisushi.png` | Club Sandwich |
| `spicyricecracker.png` | Spicy Chip |
| `ikayaki.png` | Chorizo |
| `hotsoursoup.png` | Tom Yum |
| `ramune.png` | Lemonade |

Food sprites are in `textures/food/` and `textures/food/new_shrine/`. Ramune is in `textures/drinks/` and `textures/drinks/new_shrine/`.

For Ramune's drink stream, use a pale clear blue: **`#B8E8F4`**.

`review.png` is a 4× nearest-neighbor review sheet; the game assets themselves remain 32×32.
