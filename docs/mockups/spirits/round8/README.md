# Spirits round 8

Ten ImageGen paintings placed on transparent 1120×1120 canvases with baseline y=1080. The art was scaled proportionally to the requested baby/kid/adult stage height. `sheet_1120.png` shows all ten full-size canvases; `sheet_56.png` contains the 56×56 readability reductions; `sheet_56_zoom.png` enlarges those with nearest-neighbour for review; `overview.png` is a labeled overview. The five spirits approved unchanged in round 7 are not duplicated here. No game assets or code were changed.
