# Spirits round 4 — Fire first batch

Seven concepts generated with ImageGen, using the October spirit references. Two generation tries were made for each slot; this delivery keeps the selected best try as `<id>_source.png` and its 56×56 sprite as `<id>.png` (Hinotama uses the version with the clearer curling tail). Sprites were smoothly resized from the transparent source art without palette reduction, then centered on the requested canvas; Hinoko is 30 px tall and the six kids are 34 px tall.

`all_7.png` is a review sheet of the selected sprites. No balls, layers, poses, silhouettes, CSVs, or game assets are included.
