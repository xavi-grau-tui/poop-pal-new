# Spirits round 2 review delivery

Three concept directions are provided in `concept_a/`, `concept_b/` and `concept_c/`. Each folder contains the five baby spirits and all 24 Fire realm slots, including 56×56 transparent character sprites and 24×24 ball icons. The babies are shared by their realm slot (Ember is the Fire baby).

## Review files

- `babies_three_concepts.png`: all five idle babies for A, B and C.
- `fire_three_concepts.png`: compact full Fire-tree comparison across all concepts.
- Per concept: `fire_sheet.png` is the 4× Fire tree layout; `fire_sheet_1x.png` is its actual-grid counterpart; `fire_balls.png` and `fire_silhouettes.png` review minigame scale and shape; `babies_sheet.png` shows the five baby poses.

Each concept folder includes `names.csv`, a README, ImageGen source strips under `source_strips/`, and the baby poses and aligned animation layer aids under `babies_px/<id>/`. All final sprites are nearest-neighbour reductions on hard alpha to the requested 56×56 grid. This is a concept review delivery; no game files were installed or edited.
