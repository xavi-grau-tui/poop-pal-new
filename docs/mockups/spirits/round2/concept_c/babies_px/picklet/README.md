# picklet

Five 56×56 transparent poses: idle, blink, happy, eat and sad. `body.png`, `eyes.png`, `mouth.png`, `eyes_closed.png`, `mouth_open.png` and `loose_part.png` are animation-layer aids aligned to the same canvas. `pivots.txt` records baseline and suggested pivots. Full-pose PNGs are the authoritative review frames.
