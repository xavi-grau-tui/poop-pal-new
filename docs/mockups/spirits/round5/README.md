# Spirits round 5 — selected ImageGen source paintings

This batch contains source paintings only for the three requested redos and four new Fire spirits. Two ImageGen takes were generated per slot; the selected source PNGs are preserved at their original resolution. The 56 px sprites are intentionally not included for your team to make.

Selected concepts: Karako (`paprika`), Korobi (`daruma`), Umebo (`kimchi`), Homura (`firebug`), Imori (`salamander`), Hoozuki (`hoozuki`), and Chochin (`gochujang`). `all_7_sources.png` is a presentation sheet; source files remain unchanged.
