# Spirits round 3 — Concept A (first review batch)

**Direction:** Hyakki Parade. The accepted A cartoon style continues; B and C stop at round 2.

This first batch contains the revised Fire realm and the complete Mountain realm. The five baby poses/layers are included because the round 3 brief asks for the wider shared baby designs. Moon, Fox and River are intentionally not started; the brief says to wait for feedback after this delivery. `names.csv` includes all 120 tree slots, while character PNGs and realm sheets in this batch are only for the current Fire and Mountain delivery.

## Review
- `fire_mountain_1x.png`: both realm sheets side by side at actual grid scale.
- `concept_a/fire_sheet.png`, `fire_sheet_1x.png`, `fire_balls.png`, `fire_silhouettes.png`.
- `concept_a/mountain_sheet.png`, `mountain_sheet_1x.png`, `mountain_balls.png`, `mountain_silhouettes.png`.
- `concept_a/babies_sheet.png`: five shared babies across idle, blink, happy, eat and sad poses.

All source studies are ImageGen paintings in `concept_a/source_mountain_*.png`; final sprites are cut, palette-reduced and placed on the 56×56 grid with hard alpha. Nothing was installed or written under `textures/`, `scenes/`, `scripts/` or `data/`.
