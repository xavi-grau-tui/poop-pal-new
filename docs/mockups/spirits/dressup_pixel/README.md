# Dress-up pixel pilot

Pilot items only: hitodama (3 frames), goldfish in a bubble (3), paper crane (3), zabuton (small / medium / large), and sugegasa (small / large).

`dressup_pixel_items.png` contains the transparent item artwork on the original 22-row layout. `dressup_pixel_filled.png` shows those same pixels on the unchanged reference sheet. `pilot_preview.png` extracts the five pilot rows for review. The ImageGen paintings used for the designs are in `source/`.

The paintings were fitted to the final game-pixel canvas, their colours limited to flat tones, and each game pixel exported as one exact 4×4 block. No art was made for the other rows. This is a review delivery, not a game install.
