# Spirits round 6 — selected source paintings

Seven original ImageGen source paintings. Each source PNG is preserved at its generated high resolution with transparency; the overview is scaled only for review. No 56×56 game sprites were made. No game assets or code were changed.

## Selected concepts

- `ember_source.png` — Hinoko: pale ash-coated binchotan with sleepy half-lids and glowing cracks.
- `paprika_source.png` — Shishito: calm green shishito pepper with a twitching eye and red spark at the tip.
- `dotty_source.png` — Senko: frightened molten bead hanging from twisted sparkler paper, spitting sparks.
- `kimchi_source.png` — Hinomaru: sour umeboshi centered on white rice in a bento.
- `firebug_source.png` — Homura: determined firebird chick wearing a cracked eggshell helmet.
- `salamander_source.png` — Imori: startled fire-belly newt lying belly-up.
- `ladyluck_source.png` — Gorogoro: mischievous storm cloud carrying a taiko ring.

`round6_overview.png` is the review sheet. Two or more ImageGen takes were considered per spirit; this folder keeps one selected source per slot.
