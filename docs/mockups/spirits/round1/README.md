# Spirits concept round 1 — first review batch

This delivery contains the five realm babies and the complete Fire realm (24 slots) in three visual directions. The same stable slot ids are used in all concepts. Nothing was installed into the game.

- [Concept A — Hyakki Parade](concept_a/README.md): folklore yokai and animated old objects.
- [Concept B — Sofubi Gacha](concept_b/README.md): collectible festival vinyl toys.
- [Concept C — Offering Spirits](concept_c/README.md): living spirits born from shrine offerings.
- [Baby lineup comparison](babies_three_concepts_preview_2x.png)
- [Fire realm quick comparison](fire_three_concepts_overview.png)
- [Fire realm comparison at review scale](fire_three_concepts_comparison.png)

Each concept folder contains 28 individual 80×80 PNGs (the five realm babies and the 24 Fire slots, with `ember` shared), source ImageGen family strips, `names.csv`, `fire_sheet.png`, `fire_silhouettes.png`, `babies_sheet.png`, `babies_silhouettes.png`, and `babies_px/` with the animation proof layers. Individual sprites use hard alpha and nearest-neighbour reduction from the transparent ImageGen family strip; original strips are retained in `source_strips/` for context.
