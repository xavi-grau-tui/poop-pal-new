# Torii case pilot

Vermilion lacquer with a narrow gold inset edge and an embossed torii on the back. The front is deliberately calm because the game adds its own controls and screen. `back_print.png` and `front_print.png` are the 270×480 case-grid prints. `preview.png` is the device preview from `tools/art/case_preview.py`. The original ImageGen paintings are retained as `*_imagegen_source.png`.
